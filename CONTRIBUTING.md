# Contributing

Small, reviewable changes are welcome. Discuss large protocol or UI changes in
an issue first. Use English for code, documentation and commit messages.

Run the checks in README.md before submitting a change. Protocol changes need
specification references and tests for valid, truncated and malformed input.
Use synthetic test data: never commit credentials or private session captures.

Distinguish implemented, locally tested and verified-on-server features.
Include server versions when reporting interoperability issues.

Contributions are provided under the repository's MIT license.
